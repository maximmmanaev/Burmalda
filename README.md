# Burmalda

Мобильная игра (iOS/Android) в жанре **greed survival / trace runner**.

Движок: Unity, язык: C#.

## Игровой цикл

Игрок бежит по трассе, набирая **Кристаллы Маны** — временную валюту забега — и рискуя жизнью ради большей награды. Забег строится вокруг билда из **Амулетов** и **Талисманов**, которые действуют только в рамках текущего забега и сбрасываются при смерти.

По пути встречаются **Алтари** — чекпоинты, запускающие **Ритуал** (шоп в духе Balatro), где на **Руны** можно навсегда прокачать своих **Идолов** и **Тотем**.

При смерти игрока ждёт не мгновенный проигрыш, а **d20-испытание** — бросок, дающий шанс на второе дыхание (подробности — в разделе 9 PRD).

## Прогрессия

- **Идолы** — постоянные пассивные способности (2 слота).
- **Тотем** — постоянный держатель активной способности, вызываемой двойным тапом.
- **Руны** — расходуемый ресурс Алтаря, улучшающий Идолов и Тотем навсегда.
- **Монеты** и **Кристаллы** — постоянные валюты: первая зарабатывается в игре, вторая также доступна через донат.
