# C#-глоссарий терминологии

Соответствие терминов из [docs/rules/terminology.md](../rules/terminology.md) именам
классов, полей и enum-значений в Unity/C#-коде. Единственный актуальный источник —
[PRD v6](../raw/BURMALDA_PRD_v6.md) (v4 и v5 устарели); разделы 4.2 и 5–8 обновлены/
добавлены в v6 (Ключи, Боссы, Рычаги, Достижения), разделы 9–13 не менялись
относительно предыдущих версий, но актуальный текст — см. «Остальные разделы»
в PRD v6. Стиль — Unity/C# (PascalCase для публичных членов, см.
[docs/rules/code-style.md](../rules/code-style.md)).

Список не придумывает сущностей сверх того, что описано в PRD — только даёт им
технические идентификаторы.

## Core-движение — тоннель, сетка, grid-trace (раздел 4.1)

Игрок тянет палец по соседним плитам, продвигаясь вперёд по тоннелю; нет
автоскролла камеры — давление идёт от распада плит позади (Decay, см. ниже),
не от таймера. Идентификаторы ниже реализуют саму сетку и приём/валидацию
трейс-хода; тип плиты (ловушка/валюта/артефакт) и камера — предмет других
систем/спринтов и добавляются поверх `GridCoordinate` без изменения этого
раздела.

| Термин (RU) | Раздел PRD | C#-идентификатор | Тип сущности |
|---|---|---|---|
| Плита (координата в сетке тоннеля) | 4.1 | `GridCoordinate` | struct (Core) |
| Плита (материализованная ячейка сетки, хранит и состояние распада) | 4.1 | `Tile` | класс (Core) |
| Тоннель / сетка плит | 4.1 | `TunnelGrid` | класс (Core) |
| Трейл grid-trace движения (тянешь палец по соседним плитам) | 4.1 | `GridTraceTrail` | класс (Movement) |
| Перевод точки мира (палец → плоскость пола тоннеля) в координату сетки | 4.1 | `WorldGridProjection` | struct (Movement) |
| Приём трейс-ввода пальцем | 4.1 | `GridTraceInputController` | класс (Movement) |

## Decay — распад плит трейла (разделы 4.1, 16)

Плиты позади игрока распадаются и разрушаются со временем — источник
постоянного давления вместо таймера на прохождение (раздел 4.1). Портировано
из `updateDecay()`/`tryAct()` в `legacy/burmolda_demo.html` (раздел 16:
перенос 2D top-down прототипа в 3D) без изменения констант тайминга; состояние
распада хранится прямо на `Tile` (см. выше), само тиканье — в `TrailDecaySystem`.

| Термин (RU) | Раздел PRD | C#-идентификатор | Тип сущности |
|---|---|---|---|
| Распад плит трейла (тиканье, ускорение со временем, разрушение по порогу) | 4.1, 16 | `TrailDecaySystem` | класс (Decay) |
| Плита разрушена распадом | 4.1 | `Tile.IsDestroyed` | поле (Core) |
| Порог распада плиты в секундах | 4.1 | `Tile.DecayThresholdSeconds` | поле (Core) |
| Тик распада каждый кадр (интеграция с забегом) | 4.1 | `TrailDecayController` | класс (Decay) |
