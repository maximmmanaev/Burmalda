# C#-глоссарий терминологии

Соответствие терминов из [docs/rules/terminology.md](../rules/terminology.md) и разделов
5–13 [PRD v5](../raw/BURMALDA_PRD_v5.md) (эти разделы не изменились относительно v4 —
см. раздел «Остальные разделы» в PRD v5) именам классов, полей и enum-значений в
Unity/C#-коде. Стиль — Unity/C# (PascalCase для публичных членов, см.
[docs/rules/code-style.md](../rules/code-style.md)).

Список не придумывает сущностей сверх того, что описано в PRD — только даёт им
технические идентификаторы.
