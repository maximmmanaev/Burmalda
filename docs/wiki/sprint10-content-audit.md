## Вопросы к Max

Своих ответов не придумывал — ниже открытые вопросы, как есть.

1. **Знамения: 3 или 6?** Расхождение объяснимо: 3 — из релизного минимума
   (`docs/wiki/roadmap.md`, «Релизный объём контента»), 6 — полный каталог
   PRD v7 §20 (`OmenId`, уже весь реализован в коде). Если верны оба
   чтения (6 реализовано, 3 из них — релизный минимум, остальные 3 —
   что?), пункт закрыт с запасом; нужно подтверждение, что имелось в виду.
2. **Идолы/Тотемы**: сколько именованных экземпляров нужно на релиз?
   Контент-чеклист (issue #111) числа не называет вообще.
3. **Ярусы Глубины**: чем содержательно должны отличаться Ярусы 1/2/3 —
   сложность сегментов, визуал, что-то ещё? Сейчас код не ограничивает
   Ярус сверху и не курирует контент по Ярусам.
4. **Анимация Босса**: делать ли debug-визуал боевой плитки для текущей
   механики (`Boss.Resolve`), если PRD v8 заменяет саму встречу Комнатой
   Босса (Спринт 11) — есть риск потратить работу на визуал, который
   выбросится вместе с механикой в ближайшем спринте.
