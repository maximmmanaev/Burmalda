# Changelog

## 2026-08-06

- Организована трёхуровневая документация: `docs/raw/` (неизменяемые вводные пользователя), `docs/wiki/` (живая документация), `docs/rules/` (правила для агента, разбитые на отдельные файлы).
- Корневой `CLAUDE.md` сокращён до краткого файла со ссылкой на `docs/rules/index.md`.
- Добавлен PRD v4 (`docs/raw/BURMALDA_PRD_v4.md`) как неизменяемый источник истины.
- Разработка Burmalda разбита на 12 спринтов по 2 недели (от HTML-прототипа до релиза в сторы), для каждого создан [GitHub Milestone](https://github.com/maximmmanaev/Burmalda/milestones) и набор issues с метками `feature`/`balance`/`refactor`/`infra`. См. [Roadmap](roadmap.md).
- Добавлен CI-workflow `.github/workflows/unity-tests.yml` — прогон Unity Test Framework на каждый Pull Request через `game-ci/unity-test-runner@v4`. Пока в репозитории нет Unity-проекта, шаг тестов пропускается без падения джобы. См. [docs/rules/ci.md](../rules/ci.md).
- PRD обновлён до v5 (`docs/raw/BURMALDA_PRD_v5.md`): игра переведена в 3D (камера от третьего лица сверху, персонаж не отображается — виден только трейл плит), движение теперь визуально вперёд, а не вверх; механика ввода (трейс-выбор пальцем) не изменилась. Добавлен новый тип ловушки — активируемые подвижные (стрела/лезвие) с таймингом прохода. [Roadmap](roadmap.md) обновлён (ссылки на PRD переведены на v5, описания Спринтов 1–3 дополнены), 9 существующих issues получили пометку об изменениях, создан новый issue на подвижные ловушки в Спринте 3 (#45).
- Закрыты issues #3 и #5: добавлен [C#-глоссарий](csharp-glossary.md) (соответствие терминологии PRD именам классов/полей/enum для будущего Unity-кода, разделы 5–13), и `legacy/burmolda_demo.html` переименован под терминологию v4 — чекпоинты → Алтарь (открывает Ритуал), ключи → Кристаллы Маны; логика, баланс и вид (2D) прототипа не менялись.

## 2026-08-07

- Закрыт issue #4: организована структура `Assets/Scripts/` под архитектуру Burmalda — по одной пустой папке (с `.gitkeep`) на каждую систему из [C#-глоссария](csharp-glossary.md): `Core`, `Movement`, `Decay`, `Traps`, `Currencies`, `Artifacts`, `Altar`, `RelicHall`, `D20`, `Camp`, `Monetization`. Реальные классы не добавлялись — это задел под будущие спринты. См. `Assets/Scripts/README.md` (соответствие папок спринтам) и [Roadmap](roadmap.md).
- `.gitignore` дополнен записью `.DS_Store`.
