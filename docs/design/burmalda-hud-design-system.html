Заметки для разработчика — HUD
  • Ресурсы (Кристаллы Маны, Ключи, Монеты) — источник: профиль игрока, обновляются анимацией счётчика при каждом подборе. Всегда крупный Rubik, не мельче 15px в масштабе 360px.
  • Билд (2 Талисмана + 2 Амулета) — источник: активная сборка из Алтаря. Пустые слоты — пунктирная рамка, не скрывать.
  • Вес и Реликвии — сумма веса несомых Реликвий; растёт скорость обрушения на обратном пути. Обновлять сразу при подборе.
  • Множитель в Комнате Босса — самый крупный элемент экрана, крупнее любого другого числа в игре. Растёт по ходу комнаты.
  • Полоса волны — дистанция до наступающей сзади волны обрушения; линейно уменьшается, ускоряется от Знамений/Веса.
  • Отклик Шахты (Эхо) — визуальный праздничный момент на весь экран при подборе редкой плиты; удваивает множитель.
  • Подсказка при примеривании — текст фиксированный: сообщает только «что-то не так». Никогда не показывать тип опасности или % разрушения числом.
  • Нижняя треть (267px из 800 / 533px из 1600) — зарезервирована под палец. Никаких счётчиков, кнопок или предупреждений там не размещать.
