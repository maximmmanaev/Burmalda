# Burmalda — дизайн-система HUD (из Claude Design), переведено под Unity

Источник: `docs/design/burmalda-hud-design-system.html` — рабочая копия реального
документа из Claude Design (вытащена из `.dc.html`-бандла, шрифты по внутренним
id не подгрузятся при локальном открытии, но цвета/раскладка — точные,
инлайн-стили, ничего не додумано). Открой в браузере, чтобы увидеть layout
живьём.

Цвета в исходнике заданы в `oklch()` — Unity/C# это не понимает, ниже честная
конвертация OKLCH → sRGB (формулы Björn Ottosson, стандартные, не на глаз).

## Типографика

- **Rubik** (700–800) — все числа и заголовки экранов. Счётчик ресурса — не
  меньше 15px в масштабе 360px ширины экрана.
- **Inter** (400–600) — интерфейсный текст, подсказки, кнопки, флейвор.
- **JetBrains Mono** — служебные лейблы (ЯРУС, служебные подписи), всегда
  uppercase, letter-spacing ~0.08em.

## Компоненты (из раздела «Компоненты» дизайн-системы)

- **Карточка предмета**: рамка = цвет тира редкости (обычная/редкая — золото
  `#EAB532`, легендарная — розовый `#EF82CD`), скругление 16px, лёгкий
  градиент фона, тень.
- **Кнопки**: первичная — золотой вертикальный градиент `#F4BF3F → #CD8800`
  с hard-shadow `#975800` (эффект «нажимной» кнопки), вторичная — камень
  `#23140B` с рамкой `#45342A`, опасная — красный градиент
  `#F75D59 → #BA2B2E`.
- **Число + множитель**: число всегда крупное (Rubik 800), множитель —
  золотая «таблетка» с мягкой пульсацией (`pulseGlow`, 2.4s).
- **Слот иконки**: заполненный — сплошная золотая рамка 2px; пустой —
  пунктирная рамка `#554339`, пустые слоты НЕ скрывать.
- **Модалка**: камень-поверхность + тонкая золотая линия-разделитель
  сверху заголовка.

## HUD — 4 состояния забега

Экран 360×800 в разметке (масштаб реальных 720×1600, portrait). **Нижняя
треть экрана (267 из 800px) — зона большого пальца, туда ничего важного не
класть** — это явное требование из дизайна, а не моё добавление.

1. **Пусто / перед спуском** — 3 счётчика валют слева-сверху (все 0),
   Ярус справа-сверху, 4 пустых слота билда (2+2, разделены вертикальной
   чертой), надпись «Вес 0».
2. **Обычный тоннель** — те же счётчики с реальными числами, слоты билда
   частично заполнены (сплошная золотая рамка + 2-буквенный код предмета),
   счётчик «N реликвий / Вес N» справа.
3. **Примеривание (aiming)** — весь HUD притушен (`opacity: 0.55`), кроме
   текущего числа маны и яруса; на плитке — пульсирующая красная рамка;
   всплывающая подсказка **с фиксированным текстом «С этой плитой что-то не
   так…»** — **никогда не показывать тип опасности или % разрушения
   числом**, это прямое требование дизайна.
4. **Комната Босса** — рамка экрана золотая с свечением, полоса «волна
   приближается» сверху, огромный множитель по центру (Rubik 800, 128px —
   крупнее любого другого числа в игре), плашка «Отклик Шахты: Эхо ×N»
   розовым (`#EF82CD`).

## Заметки дизайнера (перенесены дословно из документа)

- Ресурсы (Кристаллы Маны, Ключи, Монеты) — обновляются анимацией счётчика
  при каждом подборе, крупный Rubik, не мельче 15px в масштабе 360px.
- Билд (2 Талисмана + 2 Амулета) — пустые слоты пунктирной рамкой, не
  скрывать.
- Вес и Реликвии — сумма веса несомых Реликвий, растёт скорость обрушения
  на обратном пути, обновлять сразу при подборе.
- Множитель в Комнате Босса — самый крупный элемент экрана.
- Полоса волны — дистанция до наступающей сзади волны обрушения, линейно
  уменьшается, ускоряется от Знамений/Веса.
- Отклик Шахты (Эхо) — визуальный праздничный момент на весь экран при
  подборе редкой плиты, удваивает множитель.
- Подсказка при примеривании — текст фиксированный «что-то не так»,
  никогда не показывать тип опасности или % числом.

## Аудит: что из этого уже есть в коде, а что — нет (проверено, не на глаз)

**Есть и можно реально подключить (Состояния 1–2):**
- Валюты — `RunCurrencyAccumulator` / `CurrencyController` существуют.
- Ярус — `RunDepthTier` существует.
- Артефакты как каталог — `ArtifactCatalog` существует (5 из 15
  предметов, см. более ранний аудит спринта).

**НЕ существует в коде — только визуальный шелл, без логики (флаг для
агента, чтобы не придумывал):**
- Слоты билда «2 Талисмана + 2 Амулета» как экипированный лоадаут —
  такого понятия в коде не нашёл (есть только каталог определений, не
  «активная сборка на забег»). Проверил `grep` по
  `MaxTalisman/MaxAmulet/LoadoutSlot/BuildSlot/ActiveTalisman/ActiveAmulet`
  — 0 совпадений.
- Вес Реликвий (`Relic.cs` — нет поля weight) и «скорость обрушения от
  веса» — не найдено.
- Волна обрушения сзади (Состояние 4) — не найдено (`CollapseWave` и
  аналоги — 0 совпадений). Это, вероятно, часть PRD v8 «Комната Босса»,
  которая, как установили раньше в этой сессии, ещё не реализована в
  Unity вообще.
- Множитель Комнаты Босса, «Отклик Шахты / Эхо» — та же история, привязаны
  к нереализованной механике v8.

Значит Состояния 3–4 в Unity подключить пока НЕКУДА — только собрать
статичный визуальный prefab/каркас на будущее, без логики, честно
сообщив об этом в отчёте, а не имитируя рабочие числа заглушками.
