# Экономия токенов на чтение

Не общая "экономь токены" — то уже закрыто разделом «Экономия контекста»
в [agent-efficiency.md](agent-efficiency.md). Здесь — конкретно, ЧТО
читать по каждому крупному источнику этого репозитория, которые проще
прочитать целиком "на всякий случай", чем точечно.

## docs/wiki/changelog.md

Только дописывается, никогда не читается целиком. Если задача прямо
требует посмотреть последние записи — `tail -n 40`, не весь файл.

## docs/wiki/roadmap.md

Читать только секцию текущего спринта: найти её заголовок через
`grep -n '^##' docs/wiki/roadmap.md`, затем прочитать диапазон строк
между этим заголовком и следующим (`sed -n` или `Read` с
`offset`/`limit`) — не файл целиком.

## docs/wiki/traps.md, docs/wiki/csharp-glossary.md

Искать нужный термин/систему через `grep -n`, читать только найденный
раздел (между его заголовком и следующим `##`) — не файл целиком.

## PRD (docs/raw/BURMALDA_PRD_v*.md)

Только разделы, на которые прямо ссылается постановка задачи — не весь
документ и не соседние разделы "для контекста".

## Код

Искать символ (`grep -rn`) вместо сканирования директорий
`Assets/Scripts/`. Читать только файлы, которые задача реально трогает —
один соседний модуль как образец, не больше (см.
[implementation-workflow.md](implementation-workflow.md)).
