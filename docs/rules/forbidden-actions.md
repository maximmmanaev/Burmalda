# Запрещённые и ограниченные действия

- НЕ трогать .unity и .prefab файлы автономно — это YAML-сцены, ломаются при автоправках. Такие изменения — только вручную.
- Баланс (кривые множителя, вероятности d20, экономика Ритуала) не менять без явного запроса — это требует плейтеста, не только кода.
- Любые изменения в системе валют/артефактов — с ссылкой на конкретный раздел PRD в описании PR.

## Послабление: черновые балансные числа при явном разрешении задачи

Начиная со спринта «Стены вместо ловушек» (issue #275) владелец продукта
может явно разрешить агенту выбирать конкретные балансные числа в рамках
одной постановки задачи (например: скорость волны, задержка триггера,
плотность ловушек) — это не отменяет правило выше («без явного запроса»),
а описывает, что именно разрешение должно требовать, если оно дано:

- Число выносится в дебаг-панель (параметризовано, не хардкод), а не
  зашивается в код без возможности живой правки.
- В коде и в описании PR число явно помечено как **черновое, ждущее
  проверки владельцем** — не выдаётся за финальный баланс.
- Разрешение действует только в рамках задачи, где оно было дано явно, — не
  переносится молча на следующую задачу/спринт.

Авторство названий, текстов и раскладок сегментов (какую ловушку куда
поставить, как назвать шаблон) по-прежнему остаётся за владельцем продукта
— послабление касается только числовых параметров, не контента.
