# Терминология (v4, обязательна к использованию)

- Алтарь — чекпоинт, запускает Ритуал (шоп в духе Balatro)
- Идолы — постоянные пассивные способности (2 слота)
- Тотем — постоянный держатель активной способности (двойной тап)
- Руны — расходуются в Алтаре, улучшают Идолов/Тотем навсегда
- Кристаллы Маны — временная валюта забега
- Монеты — постоянная валюта
- Кристаллы — постоянная валюта / донат
- Амулеты, Талисманы — временный билд забега (сброс при смерти)
- d20-испытание — бросок при смерти вместо мгновенного проигрыша (см. раздел 9 PRD)
