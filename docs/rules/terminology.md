# Терминология (обязательна к использованию)

Актуальный источник терминов — [PRD v8](../raw/BURMALDA_PRD_v8.md) (v4–v7
устарели, но большая часть базовых существительных не менялась с v4 —
обновлена сверка терминологии, Спринт 9, issue #30). PRD v8 полностью
заменяет механику Боссов (см. «Термины v8» ниже) — термины v6/v7,
относящиеся к старой механике (Перелив энергии, Печати Боссов, Созвучия),
отменены и не используются, несмотря на то что часть из них уже реализована
в коде (переходный период — см. план миграции в
[roadmap.md](../wiki/roadmap.md#миграция-кода-боссы-v7--комната-босса-v8)).
Полное соответствие термин↔C#-идентификатор —
[csharp-glossary.md](../wiki/csharp-glossary.md).

## Базовые термины (с v4, без изменений)

- Алтарь — чекпоинт, запускает Ритуал (шоп в духе Balatro)
- Идолы — постоянные пассивные способности (2 слота)
- Тотем — постоянный держатель активной способности (двойной тап)
- Руны — расходуются в Алтаре, улучшают Идолов/Тотем навсегда
- Кристаллы Маны — временная валюта забега (не путать с «Кристаллы»)
- Монеты — постоянная валюта
- Кристаллы — постоянная валюта / донат (не путать с «Кристаллы Маны»)
- Амулеты, Талисманы — временный билд забега (сброс при смерти)
- d20-испытание — бросок при смерти вместо мгновенного проигрыша (см. раздел 9 PRD)

## Термины v6 (см. PRD раздел 1, «Изменения v6»)

- Ключи — временная валюта забега, тратится на Ритуал (заменила Кристаллы Маны в этой роли)
- Босс — заменяет устаревший «Зал Реликвии» (v4/v5); встреча по достижении точки Босса
- Перелив энергии — Кристаллы Маны сверх требуемой Боссу энергии конвертируются в Монеты
- Реликвия — награда за победу над Боссом, расширяет Пул Идолом/Тотемом
- Достижения — условие → визуальное оповещение → разлок артефакта в Пуле

## Термины v7 (см. PRD раздел 20–26 v7; часть отменена v8 — см. ниже)

- Знамения Шахты — добровольные модификаторы забега («усложнение ↔ награда»), выбираются в Лагере перед спуском
- Ярусы Глубины — каждый побеждённый Босс = граница Яруса; постоянный рекорд глубины
- Испытания Шахты — ежедневное (общий seed + фиксированное Знамение) и еженедельное (накопительные цели)
- Таблицы Рекордов — платформенные сервисы (Game Center / Google Play Games)
- Пропуск Экспедиции — сезонный прогресс (4 недели, 50 уровней)
- ~~Созвучия~~ — бонусы за сочетание тегов Амулетов/Талисманов в билде забега; **отменены PRD v8 §27**, заменены Осями артефактов (см. ниже)
- ~~Печати Боссов~~ / Эхо Босса — Печати **отменены PRD v8 §27** (заменены Типами Боссов), Эхо Босса сохраняется, пост-релизная монетизационная глубина
- Сохранение прогресса — постоянное состояние переживает перезапуск приложения (issue #107)

## Термины v8 (см. PRD разделы 6–10, 28)

- Комната Босса — заменяет автобой лучом энергии (v6/v7): короткий забег на побег, игрок хватает Реликвию и уходит под преследованием
- Плита-Жила / Плита-Резонанс / Плита-Разлом — существуют только внутри Комнаты Босса
- Афиша Босса — заменяет индикатор энергии до Босса (v7): объявляет тип и угрозу Босса заранее
- Тип Босса — Ядовитый, Клинковый, Обвальный, Голодный; объявляется заранее, бьёт по своей оси
- Ось артефакта (Жила / Резонанс / Выдержка — Талисманы; Устойчивость / Фора / Твердь — Амулеты) — заменяет Созвучия
- Слоты билда забега — зафиксированы: 2 Талисмана + 2 Амулета
- Тир Реликвии (Обычная / Редкая / Легендарная) и Вес Реликвии — ускоряет распад плит на обратном пути
- Переброс d20 / Печать Судьбы — два способа повлиять на бросок d20 в Комнате, оба с открытыми шансами
- Отклик Шахты — награда множителем/Маной за намеренный риск, который можно было не брать (раздел 28)
