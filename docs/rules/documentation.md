# Документация

- После каждой завершённой задачи агент обязан обновить relevant страницы в docs/wiki/ и добавить запись в docs/wiki/changelog.md. Ссылки в docs/wiki/index.md должны всегда соответствовать актуальному списку страниц.
- Запись в changelog.md — не длиннее 10 строк: что изменено, issue/PR,
  результат полного прогона EditMode (зелёный/что упало). Подробности
  (разбор бага, альтернативы, скриншоты) — в описание PR, не в changelog.
  changelog.md только дописывается — см. [token-economy.md](token-economy.md)
  о том, как его читать.
- Остальные wiki-страницы (roadmap.md, traps.md, csharp-glossary.md и
  т.д.) при изменении состояния системы править НА МЕСТЕ (обновить
  актуальный раздел), а не дописывать очередную секцию с историей в конец
  файла — история уже живёт в changelog.md. Существующие исторические
  секции прошлых правок не переписывать задним числом.
