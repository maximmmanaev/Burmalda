# Промт для Claude Design — тайлы тоннеля в тёплой палитре

Идея: Claude Design рисует кодом (SVG/CSS), а не диффузионной моделью — значит
цвет задаётся точным hex-кодом и не «уплывёт» в бирюзу, как было с Scenario.
Для плоских геометричных Duolingo/Mimo-форм это может подойти даже лучше, чем
генеративная модель — она хороша для фотографичных текстур, а не для чистой
плоской векторной графики.

Ограничение: Claude Design не экспортирует PNG напрямую — это HTML/CSS/SVG-
страница. Экспорт в PNG-текстуру для Unity нужно будет сделать через
скриншот/DevTools "Save as PNG" каждого тайла по отдельности (или попроси
Claude Design сразу выложить тайлы по 1024×1024px на белом/прозрачном фоне,
чтобы обрезка была ровной).

---

## Промт (вставить в Claude Design как есть)

```
Сделай HTML-страницу с сеткой плоских векторных SVG-тайлов для мобильной
игры про шахту-гробницу, в стиле Duolingo/Mimo: толстый ровный тёмно-
коричневый контур на каждой фигуре, плоские заливки без сложных градиентов
(максимум лёгкий двухтоновый переход для объёма), скруглённые дружелюбные
формы, читаемый силуэт.

СТРОГО тёплая палитра, без единого холодного оттенка (это критично — ни
бирюзы, ни мяты, ни голубого, ни циана нигде):
- база камня: #E8C284 (светлый песчаник) и #C99A5B (тень камня)
- тёплая тень/шов: #8B5A2B
- контур: #4A2E1A
- акцент опасности: #FF5A36 (тёплый красно-оранжевый)
- акцент ценности/награды: #FFC800 (золото)
- акцент игрока: #FFB300 с более ярким #FFD54F внутри (солнечный жёлто-
  золотой)

Каждый тайл — отдельный квадратный SVG viewBox 0 0 512 512, ЗАПОЛНЯЕТ весь
квадрат край-в-край: без белого/прозрачного паддинга по краю, без рамки-
карточки, без скруглённых углов у самого холста, без отбрасываемой тени под
тайлом (это должна быть текстура пола, а не иконка-стикер).

Сделай 5 тайлов, разложи их подписанными карточками в сетке 5×1 на странице
(подпись под каждым — просто текст, не часть самого SVG):

1. "База" — обычная плита тёсаного песчаника, у камня видны стыки/кладка,
   без трещин и без акцентов.
2. "Распад" — ТА ЖЕ базовая текстура камня, что и в тайле 1 (не другой
   рисунок), поверх неё добавлены жирные тёплые оранжево-коричневые линии
   трещин — рисунок камня под трещинами должен читаться так же, как в
   тайле 1.
3. "Опасность" — та же базовая плита камня, с одним общим приёмом:
   тонкая пульсирующая кайма/свечение цвета #FF5A36 по контуру трещин или
   краю плиты. Этот приём должен быть узнаваем и одинаков на любой опасной
   плите — сделай его максимально простым и графичным.
4. "Ценность" — та же базовая плита камня, с одним общим приёмом:
   несколько простых блик-искр цвета #FFC800, визуально явно не похожим
   на приём опасности (не свечение по контуру, а именно точечные блики).
5. "Игрок" — самый заметный тайл набора: та же базовая плита камня, в
   центре крупный простой солнечный символ (диск с лучами или руна),
   цвета #FFB300/#FFD54F, с контуром #4A2E1A. Должен читаться с одного
   взгляда и выделяться среди всех остальных плит даже в движении —
   это самый важный ассет из пяти, не экономь на контрасте.

Никакого текста и вотермарок внутри самих SVG. Простой, чистый, минимальный
HTML вокруг — просто сетка карточек с подписями, без лишнего UI.
```

## Что делать с результатом

1. Открой результат в Claude Design, попроси подправить конкретный тайл,
   если что-то не так (например «сделай трещины на тайле 2 толще» —
   Claude Design умеет точечно редактировать через чат/инлайн-комментарии).
2. Когда устроит — вырежи каждый SVG-тайл по отдельности (в DevTools можно
   скопировать сам `<svg>...</svg>` и сохранить как файл, либо сделать
   скриншот с обрезкой ровно по границе квадрата) и сохрани как
   `tile-fresh.png` / `tile-half-decayed.png` (трещины) / … по той же схеме
   имён, что уже используется в `Assets/Art/Tiles/`.
3. Принеси готовые файлы сюда или сразу положи в `Assets/Art/Tiles/` — с
   ними я смогу продолжить работу (или сравнить с тем, что уже подставлено).
