# Burmalda — правила для агента

Мобильная игра (iOS/Android), жанр greed survival / trace runner.
Движок: Unity, язык: C#.

## Терминология (v4, обязательна к использованию)
- Алтарь — чекпоинт, запускает Ритуал (шоп в духе Balatro)
- Идолы — постоянные пассивные способности (2 слота)
- Тотем — постоянный держатель активной способности (двойной тап)
- Руны — расходуются в Алтаре, улучшают Идолов/Тотем навсегда
- Кристаллы Маны — временная валюта забега
- Монеты — постоянная валюта
- Кристаллы — постоянная валюта / донат
- Амулеты, Талисманы — временный билд забега (сброс при смерти)
- d20-испытание — бросок при смерти вместо мгновенного проигрыша (см. раздел 9 PRD)

## Правила для агента
- НЕ трогать .unity и .prefab файлы автономно — это YAML-сцены, ломаются при автоправках. Такие изменения — только вручную.
- Баланс (кривые множителя, вероятности d20, экономика Ритуала) не менять без явного запроса — это требует плейтеста, не только кода.
- Любые изменения в системе валют/артефактов — с ссылкой на конкретный раздел PRD в описании PR.
- Код — C#, стиль Unity (PascalCase для публичных членов, camelCase для приватных).

## Git-процесс
- НИКОГДА не пушить напрямую в master/main.
- Для любой задачи: создать новую ветку, закоммитить изменения, запушить ветку, открыть Pull Request через `gh pr create`.
- Мерж PR делает только пользователь вручную на GitHub.
